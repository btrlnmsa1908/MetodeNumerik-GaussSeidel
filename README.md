## Deskripsi

Proyek ini merupakan implementasi Metode Numerik Gauss-Seidel untuk menyelesaikan sistem persamaan linier yang digunakan dalam simulasi optimasi distribusi pengiriman UMKM.

## Pemodelan Matematika

2x1 + x2 + x3 = 100

x1 + 3x2 + x3 = 120

x1 + x2 + 2x3 = 110

Keterangan:

* x1 = Pengiriman Area A
* x2 = Pengiriman Area B
* x3 = Pengiriman Area C

## Hasil

x1 = 22.857145

x2 = 21.428572

x3 = 32.857141

Error Akhir = 0.000007

Jumlah Iterasi = 14

## Cara Menjalankan

python gauss_seidel.py
